Política de Privacidade

Viajes Cusco Perú — última atualização: 2026

Quem somos

Viajes Cusco Perú é uma agência de turismo que opera em Cusco, Peru. Este site (promo.viajescuscoperu.com) é uma página de ofertas usada para divulgar nossos pacotes turísticos.

Quais dados coletamos

  • Dados de navegação: página visitada, tempo de permanência e até onde você rolou a página.
  • Parâmetros de origem do anúncio (UTM) quando você chega através de uma campanha publicitária.
  • Cliques em botões de contato (WhatsApp, telefone, email, redes sociais).
  • Se você preenche o formulário de contato, os dados que você digita (destino, data, número de viajantes) — usados apenas para gerar a mensagem de WhatsApp, não ficam salvos em nosso banco além do registro de que o clique aconteceu.

Como usamos essas informações

Usamos esses dados para entender de onde vêm nossos clientes, medir quais anúncios funcionam melhor e responder mais rápido pelo WhatsApp. Também usamos o Meta Pixel (Facebook/Instagram) para medir a efetividade de anúncios e, eventualmente, mostrar anúncios a pessoas que já visitaram o site (remarketing).

Com quem compartilhamos

Não vendemos seus dados a terceiros. Utilizamos os serviços de Supabase (armazenamento de dados) e Meta/Facebook (Meta Pixel) apenas para as finalidades descritas acima.

Seus direitos
